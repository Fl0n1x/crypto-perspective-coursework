# Курсова робота: оцінка перспективності криптовалют

Пашко Назарій, СА-32, МЕТОДИ ТА ЗАСОБИ ПРИКЛАДНОЇ СТАТИСТИКИ, Львів-2026.

## Задача

Для монети, що торгується на Binance, спрогнозувати на момент закриття
тижня, чи буде її дохідність за наступні сім днів вищою за дохідність
медіанної монети того самого тижня. Бінарна класифікація, одиниця
спостереження - монета в конкретному тижні.

## Чому ціль визначена відносно медіанної монети, а не відносно BTC

Дохідність монети складається зі спільного руху всього ринку та власного
відхилення монети від нього. Перша складова однакова для всіх монет тижня
й з ознак окремої монети не виводиться. Якщо ціллю зробити «випередити
біткоїн», у тижні падіння альткоїнів майже всі мітки будуть нульовими, а
в тижні зростання - майже всі одиничними, тож модель вчитиметься вгадувати
ринок замість порівнювати монети. Порівняння з медіанною монетою того
самого тижня цю спільну компоненту усуває: класи стають збалансованими
(49,9 %) незалежно від фази ринку.

## Дані

Панель «монета - тиждень»: 65 820 записів, 384 монети, 298 тижневих точок
з 3 січня 2021 по 13 вересня 2026 року, 19 числових і 2 категоріальні
ознаки. Джерела:

- **Binance Spot API** - повна денна історія OHLCV для пар до USDT;
- **CoinGecko API** - довідник монет, капіталізація та секторні категорії.

Усі ознаки рахуються каузальними ковзними вікнами: значення на момент
прогнозу використовує лише дані до цього моменту. Горизонт цілі дорівнює
тижню, тому періоди сусідніх спостережень не перекриваються.

## Результати

| Етап | ROC-AUC |
| --- | --- |
| Наївний класифікатор | 0,500 |
| Базовий конвеєр, крос-валідація | 0,545 |
| Фінальний конвеєр, крос-валідація | 0,551 |
| Базовий конвеєр, тест | 0,537 |
| Фінальний конвеєр, тест | 0,552 |

Результат на тесті не поступається крос-валідації, тобто конвеєр не
переоцінений. Практична перевірка на тестовому періоді: відібрані моделлю
20 % монет давали в середньому 0,43 % за тиждень проти мінус 1,90 % у
медіанної монети ринку.

Для порівняння, той самий конвеєр, оцінений на даних навчання, дає
ROC-AUC 0,756. Різниця показує, наскільки некоректний протокол перевірки
завищує результат.

## Каталог bonus

Містить історію пошуку моделі на попередній, місячній панелі: підбір
гіперпараметрів, покрокову валідацію, порівняння цільових змінних і
симуляцію портфелів. Розбір у `bonus/bonus_report.md`. До оцінювання
курсової ці матеріали не належать, але саме там знайдено рішення про
крос-секційну ціль, яке покладено в основу роботи.

## Обмеження

Вибірка містить лише монети, що торгуються станом на момент збору даних,
тому зміщення виживання не усунене. Дані взято з однієї біржі. Модель
оцінює відносний результат монети й не прогнозує напрям ринку загалом.
